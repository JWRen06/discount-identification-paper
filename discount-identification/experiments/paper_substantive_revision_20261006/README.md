# 联合成本校准与独立控制器验证

这里的数据为独立实现的受控回放，均为合成输入，不是机构或人类行为记录。

- `calibration_and_decision_results.json`：成本导数、误校准见证、1280次联合盒检查、3500次决定实验、27行估计对照及两组原始回放的审计结果。
- `paired_replay_observation_logs.json`：两组规则各1000次、三环境八阶配对聚合观测。供审计使用的字段不含私有目标或政策参数。
- 求解端为上级目录`independent_tracking_controller_20261006.py`，从Bellman方程求政策，不调用论文的响应或反演公式。
- 审计与实验为上级目录`paper_calibration_audit_20261006.py`，种子2026100603；连续比例盒细分后逐盒反演，符号或数值不确定时保留全域。

真实参数仅用于实验验证与覆盖评价。校准比例盒、配对观测误差的次高斯上界和任务门槛是外部输入，本目录不提供现场校准证据。只在共同模型条件成立时解释时钟验收；非空Euler兼容集合不认证整个模型。

统一复现入口为上级目录`paper_upgrade_reproduce_20261006.py`，使用临时目录，不改写本目录归档。
