## 复现

逐字节对照使用 Python 3.12.14、NumPy 2.3.5、openpyxl 3.1.5。

```sh
python -m pip install -r requirements.txt
python experiments/paper_review_reproduce_20261006.py
```

上面的入口复现六项代数证书和一项早期市场字段计算，不需要补齐外部原件。

完整实验需要先按 [DATA_SOURCES.md](DATA_SOURCES.md) 补齐指定版本的第三方输入，再运行：

```sh
python experiments/paper_upgrade_reproduce_20261006.py
```

完整入口在临时目录重算并对照归档，不覆盖归档结果。直接运行其他单项实验可能改写本包中的对应结果，建议先复制到临时目录。

## 结论范围

有限异质正池的一般位置识别不保证统一噪声稳定性；10^-6噪声失败保留。公开程序反事实动作不是机构交易或投资者偏好的实证识别。WTI重叠样本已排除计分，后续评价是回顾性敏感性分析，不构成新的严格未见样本。
